# Portfolio (React + Vite)

    npm install
    npm run dev

- Edit your info, skills and projects in `src/data.js`.
- Put your photo at `public/profile.jpg`.
- Each section lives in its own file in `src/components/`.

- Hero background video: put a short looping MP4 at `public/hero-bg.mp4` (5-10s, under 5 MB, no audio needed).
